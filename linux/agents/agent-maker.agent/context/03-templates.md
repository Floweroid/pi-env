# Agent.md 模板

## 精简模板（推荐）

适用：大多数 agent，职责明确。

```markdown
---
name: <agent-name>
description: <一句话说清干什么>
---

你是一名 <角色> agent。

职责：
- <职责 1>
- <职责 2>
- <职责 3>

行为准则：
- <准则 1>
- <准则 2>
- <准则 3>
```

## 扩展模板

适用：复杂 domain，需要更多上下文。

```markdown
---
name: <agent-name>
description: <一句话>
tools: tool1, tool2
model: provider:model-id
---

你是一名 <角色> agent<，运行环境/背景>。

核心职责：
- <职责 1>
- <职责 2>
- <职责 3>

行为准则：
- <准则 1>
- <准则 2>

输出格式（可选）：
- <格式约束>
- <代码块要求>

注意事项（可选）：
- <边界条件>
- <已知坑>
```

## 模板使用原则

1. **从精简模板开始** — 不要一开始就写很长的 prompt
2. **职责列表不超过 8 条** — 超过说明角色边界模糊
3. **行为准则不超过 5 条** — 只写最关键的约束
4. **不用写"你好""请""谢谢"等寒暄** — 这是 system prompt，不是聊天
5. **少用形容词，多用可验证的指令** — "修改配置前先备份" 比 "注意安全" 好
